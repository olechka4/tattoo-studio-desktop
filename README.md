# Приложение для тату-студии

## Название и что делает

**Название:** Приложение для тату-студии

**Что делает:**  
Приложение позволяет клиентам регистрироваться и записываться на тату к конкретному мастеру в выбранную дату и время. Администратор видит всех клиентов и все записи. Клиент видит только свои данные.

## Стек технологий

1. Python 3
2. SQLite (база данных)
3. Tkinter (графический интерфейс)
4. hashlib (хэширование паролей)

## Как установить

1. Установите Python 3.10 или выше с официального сайта (если ещё не установлен). При установке обязательно отметьте галочку "Add Python to PATH"

2. Скачайте папку с проектом на компьютер

3. Откройте командную строку (cmd) или терминал

4. Перейдите в папку с проектом командой:
   ```cmd
   cd C:\Users\profi\Desktop\MDK_01.04\tattoo_studio
5. Установите дополнительные библиотеки (если используются):
   pip install tkcalendar
   (Tkinter и hashlib уже встроены в Python, дополнительно устанавливать не нужно)

## Как запустить

1. Откройте командную строку (cmd) или терминал
2. Перейдите в папку с проектом:
   cd C:\Users\profi\Desktop\MDK_01.04\tattoo_studio
3. Выполните команду:
   python main.py
   (если не работает, попробуйте python3 main.py)
4. Откроется окно приложения
5. Для входа:
   - Клиент: нажмите "Регистрация", создайте аккаунт, затем войдите
   - Администратор: логин admin, пароль admin123
